# Archived Web4 Historical Evidence

This directory contains **historical Web4 evidence / closeout / pre-main documents** that remain useful for audit and retrospective reading, but should not be mistaken for the current repository truth-source.

Use these files to answer questions like:
- what passed in a specific historical repair round;
- what the closeout bundle recorded on that date;
- what the old pre-main evidence procedure looked like;
- what the historical Web4 phase snapshot and V0 interface baseline said at that time.

Typical files archived here include:
- historical evidence / closeout bundles
- pre-main evidence runbooks
- phase snapshots
- V0 interface baseline docs

Do **not** use this directory to decide whether the current repository is release-ready.

Current truth-source order:
1. `RELEASE_READINESS.md`
2. `docs/WEB4_INFRA_PLATFORM_DEVELOPMENT_MASTER.md`
3. `docs/reports/TRNM_WEB4_PLATFORM_SCORECARD_2026-03-31.md` (when present in the current checkout)
4. this archive directory only for historical evidence
