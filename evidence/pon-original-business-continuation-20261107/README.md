## Source changes

Ordinary classical V3 startup now installs the existing pure mathematical
rejection cache with 256 slots and a 30-second lifetime, unless an explicit
positive configuration is already present. Retained Rust objects are bounded
by 32 KiB; this is not an RSS assertion. Complete proof bytes, profile, challenge,
task and target identify each fact. Only fully completed native Transcript or
Product failures can be retained. Contention and poison fall through to the
native verifier. New and valid proofs keep full verification. Current caller,
Node context, original CPU owner, deadline and cancellation remain checked.
No cached refusal can create VerifiedWork or execution priority. The PQ, Growth
and separately selected arithmetic profiles do not receive this default.

The additional request facts distinguish exact matches, returned cached
refusals, verifier entry, actual replay and publication. CPU measurements retain
their original nested intervals. Exact TTL seconds and nanoseconds are recorded;
the millisecond field is only a truncated display. Fresh-challenge evidence may
not claim a cached exact statement as new work. Missing observations stay
unknown, and impossible completed-path combinations are refused by the reader.

Classical Legacy admission can reuse a single fully reconstructed historical
parent State during its child's post-write readback in the same original SQL
transaction. All original expected writes and triggers run before the parent is
read and compared. The child still reads its actual SQL linkage, delta and root;
an actual child snapshot follows the original path. Active-parent KV reads are
a different authority source and cannot lend a historical prefix. PQ, Growth
and Authenticated paths are excluded. The original transaction, closed ordinary
table schema, no-write epoch and final callback fence remain mandatory. A schema
that cannot qualify uses both original reads; transaction identity failure is
an integrity error. This does not claim general Blob/backup/UDF/filesystem
immutability, cross-request State authority, or touched-set migration.
