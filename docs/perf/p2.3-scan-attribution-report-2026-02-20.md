日期：2026-02-20
分支：`feat/p2.3-candidate-scan-attribution`

## 1) 目标
在不修改默认快路径语义下，验证 `aggressive/original` 比率是否可由 `candidate_groups_scanned` 解释。

## 2) 输入数据
- 回归矩阵 CSV：`trillionnium/run/bench/bench-regression-matrix-20260220-154327.csv`
- profile 汇总：`trillionnium/run/bench/aggressive-profile-summary-20260220-172741.md`
- 关联分析：`trillionnium/run/bench/aggressive-scan-correlation-20260220-172922.md`

## 3) 结果摘要
- ratio（avg）
  - classic: 1.000
  - hot-streak: 0.995
  - mixed: 0.984
- scan 指标（p50/p95/max）
  - 三类 workload 均为 0（当前样本）
- 相关系数（ratio vs scan / scan_per_tx / scan_per_group）
  - 全部为 `n/a`

## 4) 结论
- 当前数据批次中，scan 指标基本无方差，无法支持“scan 变化导致 ratio 变化”的线性归因。
- 证据强度：**弱**（样本区分度不足）。
- 当前决策：**No-Go（仅就“基于本批样本做 scan 归因”）**。
