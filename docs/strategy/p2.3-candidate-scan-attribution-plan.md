## Goal
在**不改变默认快路径语义**的前提下，定位 `AggressiveGreedy` 在热点场景的主要耗时来源，形成“可验证、可回滚、可门禁化”的优化提案。

## Scope (this iteration)
1. 固化观测口径：`candidate_groups_scanned` + elapsed + workload metadata。
2. 建立热点归因对照：classic / mixed / hot-streak 三类场景统一输出。
3. 产出行动阈值：给出 No-Go / Go 的量化判据（仅实验路径）。

## Non-goals
- 不把实验策略切成默认。
- 不调整已冻结的 v1 事件字段契约。
- 不放宽 nightly 现有 hard gates。
