# One-host real-model replica research evidence

This evidence records actual public SmolLM CPU training, complete model/adapter
TCP transport through an offline-publisher replica, and 64 actual next-task
forwards. The result is **no-update: both generations scored 16/32**. It does not
qualify Hepta installation, FinalUse, independent operators, WAN availability,
model benefit, post-quantum transport or any consensus activation.

See [the scope and reproduction notes](../../docs/security/SMOLLM_CELL_REPLICA_RESEARCH_V1.md).

- `training/` retains all three original command records, execution plans,
  supervisor observations, actual receipts and immutable adapter descriptors.
- `actual/frozen-comparison.json` binds the one pre-forward random fixture to
  both already-existing artifacts. `actual/research-result.json` contains every
  actual forward observation and the unchanged false authority flags.
- `actual/transport/` retains the exact native commands, all eleven members,
  TCR1 release bytes, publisher termination, real offline connection refusal,
  replica-only fresh acquisition and cache-only final materialization.
- `failures/optimized-original/` retains the optimized build's real connection
  reset. A faster local build is not a successful full-model transfer.
- `python-environment.txt` records the installed CPU environment;
  `local-qualification.json` records original/retained evidence hashes and source
  blob identities. Only terminal empty log lines were normalized for Git.
