# Same model from one-call text training through held inference

This synthetic regression starts from `CCT00001` with two bounded text rows.
The stock native call computes their masked features and all fifteen signed
products per row, then performs the numeric training projection. All six
feature/product observations (two rows in each of a two-active, one-active
and dry case) match the complete frozen original source/execute fixture,
including nonzero positive and negative products. No product is supplied by
a Python dot or a fallback.

The original witness adds observations of the original typed Model before
and after its full unchanged `execute(Some)` call. It calls the unchanged
original canonical serializer directly on those same values. The HIA test
extracts each returned weight from its actual public CCT report, appends the
unchanged original typed router input bytes, and invokes the existing
`CMCV0001` writer. This compares every actual canonical Model byte to the
original. The subsequent test bridge decodes the actual emitted native
bytes, compares all weight words, and performs exact layout reordering and
checked signed narrowing. It computes no forward dot.

Six fixed held feature probes are then passed to existing stock Int257
ordinary inference. Both stock images and the genuine frozen linked original
`PreparedModel::ordinary` receive identical model and feature packets.
The baseline and dry Model give identical held output, despite the dry
case's real nonzero prepared products; the two-active and one-active cases
change actual held scores. The fixture does not infer a model-quality
improvement or independence in a real future population.

Unlike the separate zero-product CTRX-to-held fixture, this route begins
with actual nonzero model/products from the single published CCT call.
Unlike the original CCT differential, this test consumes the emitted
updated coefficients in a later numeric call. It neither runs a deployed
stateful Cell nor exercises proofs, authority, adoption, action delivery,
persistence, sampling, live state, or user data.
