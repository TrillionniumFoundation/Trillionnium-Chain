# TRNM Native PoCO Mainnet Rehearsal GO/NO-GO Template

Default decision: **NO-GO**.

A rehearsal may be marked conditional only when the exact commit, clean build,
binary/configuration hashes, validator identities, secure signer path,
multi-host topology, state synchronization, fault matrix, long-duration load,
observability, recovery and rollback evidence are attached.

A rehearsal result never overrides `../../../RELEASE_READINESS.md`.
