# Native PoCO Validator / Operator Handoff Template

Use this template to bind an operator handoff to one worktree, branch, commit,
binary set and configuration set.

Required: operator identity, change ticket, branch, commit, clean status, native
node hash, validator identity, key fingerprints, configuration hashes, starting
and ending roots, quorum evidence, restart/rollback commands and open blockers.

Any missing or mismatched field is NO-GO. Current release authority remains
`../../RELEASE_READINESS.md`.
