A cold request can start after accumulating a 100 ms reserve before it has a full native completion token.

A longer complete relation may hit sticky refusal first in that near-one-CPU schedule; a small cold control does not prove all allowed States are reachable.

The original 0.25 CPU / 2 GiB cgroup contract was unavailable in this execution environment.
