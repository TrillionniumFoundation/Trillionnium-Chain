129: ## 2026-10-27: Public and signed CLI loopback-proxy cost floor
130: 
131: The original `require_for_listener(source)` deliberately permits plain
132: loopback-only development without an administrator-provisioned cgroup. This
133: was still unsafe for **explicitly selected public or authenticated History
134: sync**, because a local forwarder can present remote malicious W1 bytes under
135: a loopback destination. The source locator does not attest provenance.
136: 
137: `main.rs::priced_sync_context` now selects the existing **fixed Host kernel
138: parent**, irrespective of destination IP family or loopback bit, whenever a
139: public V2/V3/growth admission profile or any authenticated-sync credentials
140: are requested. In this mode `sync_host_kernel_owner` requires an actual
141: `HostKernelBudget` for `/sys/fs/cgroup/trnmponpublic.slice`, rechecks its
142: real calling-thread membership and immutable resource ceilings, and refuses
143: before the first socket request or W1 proof if unavailable. Subsequent page
144: checks retain this same original verified budget instance. A profile with
145: partial authentication flags cannot accidentally access a cheap fallback.
146: The original `receive_page_from` contextual import retains its own checks.
147: 
148: Plain non-public, explicitly local development sync retains its original
149: loopback-only exception for compatibility, and remains outside public
150: hardening qualification. An embedding caller that directly invokes
151: `receive_page_from` can still supply a loopback address without a real
152: end-to-end source attestation; local Node ownership is a trusted
153: application boundary. A hostile local process that invokes Node admission
154: directly is not made economically honest by transport policy.
155: 
156: Added regression
157: `public_sync_cannot_use_loopback_proxy_to_avoid_fixed_host_cpu_owner`
158: compares the strict loopback caller against the original fixed kernel-parent
159: checker and covers all public profiles and partial authentication options.
160: Source-only behavior must be compiled and exercised under an actual
161: root-provisioned cgroup before P1 can be considered satisfied.
162: 
163: This removes a free loopback override for **public and authenticated CLI
164: sync**, not the unresolved developer tunnel/embedding boundary, global
165: service fairness or original W1 cheap-false-transcript economics.
166: P1-P6 and A03 remain unqualified.
