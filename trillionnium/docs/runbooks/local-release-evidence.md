# Local Native PoCO Release Evidence

Local evidence is development evidence only. Record the exact branch, commit,
clean-tree status, native node binary hash, configuration hashes, validator
identities, test commands, state roots, finality receipts and artifact hashes.

A local pass does not close the multi-host, key-management, economic-security,
soak, indexer or independent-audit blockers in `../../../RELEASE_READINESS.md`.
