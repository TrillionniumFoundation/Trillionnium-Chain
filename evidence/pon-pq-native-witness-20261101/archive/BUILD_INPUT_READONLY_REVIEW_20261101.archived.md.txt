- `CARGO_MANIFEST_DIR` is also compiled in. Keep the source/build location and

  and empty Rust flags; this is a snapshot, not a universal reproducibility claim.
- The SQLite boundary build derives cfg/env constants from the real toolchain,
  loader paths, native C tools and pinned registry SQLite sources. Its observed

  build receipt and qualified outcome; a different environment can instead embed

- Registry dependencies do have generated Rust outside the repository:
  `libsqlite3-sys` consumes `OUT_DIR/bindgen.rs`; `serde` and `serde_core` consume
  their `OUT_DIR/private.rs`. These were observed in dependency rustc dep-info.
  Their generators belong to locked dependencies; no path from these observed
  inputs to the new evidence package was found.
- The observed OpenSSL dependency output links **static** `ssl` and `crypto`
  from the prepared 3.5.9 installation and consumes its headers. Those archives,
