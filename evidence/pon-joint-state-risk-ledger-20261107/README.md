## Exact finite-state result

For every oracle table f, FJS1 checks a single common density matrix sigma,
a rational multiplier lambda of at least one, and a positive-semidefinite excess
Delta_f with

```
rho_f <= lambda * sigma + Delta_f
weighted_excess = sum_f prior(f) * trace(Delta_f)
P_actual_model(event) <= min(1, lambda * B_reference + weighted_excess)
```

Here `actual_model` means the explicitly supplied finite joint state. It is
not a statement that a physical adversary state was measured or authenticated.
The same admissible strategy is used under both states, and its reference
query/output caps must hold on all counterfactual branches. The reference bound
is recomputed from the frozen model; the caller cannot supply an arbitrary B.

[Run 02](joint-state/run-02/summary.json) includes singular independent state,
noisy first-winner advice, coherent advice, a complete truth-table register and
rare excess. Coherent advice reaches `31/256`; complete-table advice reaches
`14911/65536` without new oracle queries. These successes are accounted for by
the initial-state loss. Incomplete tables, unpaid excess, false freshness and
selected-start substitution are refused. Source files match at both run ends.
The suite has 34 tests, including 729 exact symmetric 3-by-3 matrix controls.

## Native chronology and history limits

PNRL1's real example includes unsuccessful and repeated confirmations, a
membership error, a child exiting after registration but before native dispatch,
and a child exiting after native confirmation but before its bank outcome.
Independent reconciliation requires the complete original journal rather than
a caller-selected claims list. Unfinished starts remain charged on reopening.

A particularly important retained counterexample is **bank-only rollback before
native dispatch**. At that cut a durable registration exists but the native
intent set has not changed. Restoring the old bank can still pass unpinned
consistency against the current native journal. A newer independently retained
bank checkpoint rejects it. Coherent after-the-fact allowance rewriting has the
same external-history requirement. Neither an internal hash chain nor a shared
law-scope digest supplies a physical witness or a proof of the missing law.

## Remaining scientific obligations

Actual-work closure still requires an all-algorithm physical simulation/cost
bound, an authenticated complete initial state and lifecycle/help envelope,
and a sufficient reduction from the real accepted work relation to the ideal
query experiment. FJS1 makes the finite-state loss explicit but supplies none
of those physical attestations.

Actual-native closure still requires all-relevant-view coverage, physical time
and adoptability, hidden and in-flight inventory, a joint inventory/progress law,
complete real repeated-start history, and one final probability statement in
that same law. EC1 checks coverage inside a complete finite model; PNRL1 checks
one retained native owner and declared budget. Their separate passes cannot be
multiplied or added into a real confirmation-security number without the missing
common premises. Production and actual native probability qualifications remain
false, and `global_failure_probability` remains null.
