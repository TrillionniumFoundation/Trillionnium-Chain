# Desktop publication records

These are original desktop preparation, interim C3 draft-publication and complete physical-source-audit records. They contain no native benchmark executions and do not replace ai395 execution evidence.

All original payload bytes and original relative filenames are preserved. MANIFEST.json lists each source path, size, SHA256 and source mtime. Invalid JSON is intentionally retained unchanged and listed in invalid_json; an expanded Git copy may map such files to .json.raw while recording that mapping. Do not change the raw archive or relabel earlier observations.

SHA256SUMS covers every payload plus MANIFEST.json; its own digest and the manifest digest are bound by the external transport manifest. The full compressed archive SHA256 binds all archive members. The two manifest files are packaging metadata, not original execution records.
