## Disk limit and already published artifacts

Local disk remained below the unchanged 700 MiB native-build stop line.
No new local target or native compilation was started. The full original
receipt and all unique extracted evidence were preserved.

Only after #529's 34 parts and six complete objects passed remote byte
readback, a read-only audit checked all 11 live processes, 117 file descriptors
and 11 memory maps: no references to the five explicitly authorized old ZIP
transport copies, no unreadable processes and no snapshot changes. Their
metadata and hashes matched the remotely verified objects. The authorized
single retirement released 115,970,048 allocated bytes, with all exact remote
part paths, hashes and reconstruction instructions retained in
[transport-retirement-01.json](transport-retirement-01.json).

Later the same five paths were observed to exist again. This agent did not
restore or redownload them; the cause was not established. The separate
[reappearance observation](transport-reappearance-observation.json) records
their metadata and the renewed disk constraint. No repeated deletion was
attempted. This episode does not replace or negate the actual prior remote
readback, and no unpublished #525 proof artifact was retired.
