# Trillionnium Chain documentation

The only active engineering direction is [the development plan](development/TRNM_AI_NATIVE_BLOCKCHAIN_DEVELOPMENT_PLAN.md).
The selected architecture is [PoN / Hepta-PoH](protocol/pon-nakamoto-v1/README.md): useful
work competition and a shared model commons, not a PoCO rename or another BFT layer.

[Consensus](protocol/pon-nakamoto-v1/CONSENSUS.md), [neural work](protocol/pon-nakamoto-v1/NEURAL_WORK.md),
[model commons](protocol/pon-nakamoto-v1/MODEL_COMMONS.md), [economics](protocol/pon-nakamoto-v1/ECONOMICS.md),
[reorg/migration](protocol/pon-nakamoto-v1/RECOVERY_MIGRATION.md) and
[acceptance](protocol/pon-nakamoto-v1/SECURITY_ACCEPTANCE.md) define domain contracts.
The [M00-M17 index](modules/README.md) maps actual source ownership to the new target.

[Applicability](architecture/TRNM_DOCUMENTATION_AUTHORITY_V1.md) and the
[machine target](../config/pon-nakamoto-v1.json) classify retained PoCO directories,
operation traces and crate documentation as legacy implementation/reference only.
Frozen byte/specification inputs remain unchanged for historical verification; their
presence grants no active PoCO roadmap or PoN proof authority. Git history is the archive.

Documentation integrity, cryptographic proof qualification, actual implementation,
independent model/economic acceptance and deployment are different facts. All new
runtime/production/efficacy flags remain false until their own evidence exists.
