# Bounded composed activation byte projection

This private entry takes the exact TAR1 prefix, held expected activation SHA
and raw named-object JSON, **followed by 32 separate caller-held expected
checkpoint SHA bytes**. The suffix is outside the hashed JSON range and is
never treated as JSON. The same immutable input drives native pin, strict
lexical and typed field capture, original profile and length/shape predicates,
token IDs/mask/positions, explicit digest grammars, static runtime fields and
lowercase hidden-hex conversion. None is a substitute for genuine model
provenance, authority or observer evidence.

The original frozen Rust `activation` is used directly as the test oracle on
the same inputs, with an inert test observer. HIA does not call an observer.
This follows the resource limits of TAR1 and its concrete typed projection,
including named object representation only, at most 32 keys per map, 64
primitive array entries, and 256 decoded text bytes per metadata field or
294,912 for hidden hex. Original valid positional serde forms and larger raw
or typed profiles remain private refusals. The maximum full raw input with
both pins is 1 MiB; it covers ordinary 1–64 × 576 activation bit strings.
Nonfinite binary patterns are returned unchanged, as in original activation;
numerical material assembly is a distinct stage.

The stock disjoint-buffer call writes only a u64 little-endian token count
then the exact `count * 576 * 4` decoded bytes on success; no refusal writes
output. Scratch requires 315,000 bytes. Status 1–3 are the original pin,
strict JSON and concrete field stages, then 4 original profile, 5 hash
encoding, 6 shape, 7 tokens, 8 static runtime scope, and 9 hidden bits.
Private status 100 indicates framing, 102 capacity, 103 narrower profile,
104 SHA internals. The TAR1 and typed projection entry ABIs and behavior are
retained, with logical-range composition and scratch refactoring requalified.

No files are opened, no model trained or executed, and no verified material,
trust, time, policy or live runtime state is produced.
