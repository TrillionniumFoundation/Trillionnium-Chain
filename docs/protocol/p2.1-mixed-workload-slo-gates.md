# P2.1 Mixed Workload SLO Gates

Date: 2026-02-19
Scope: `trillionnium-rust` nightly/release gate

## Purpose
把 mixed workload 基准从“可跑”升级为“可判定”，用于 nightly 与 RC 前硬门禁。

## Benchmark Profiles (fixed)

### Profile A — Mixed Balanced
- command:
```bash
cargo run -q -p trnm-bench -- \
  --workload mixed --txs 5000 --keys 1000 --read-fanout 3 --write-every 2 --profile
```
- target:
  - elapsed_ms <= 300 (warn), <= 600 (hard)

### Profile B — Mixed Write-heavy
- command:
```bash
cargo run -q -p trnm-bench -- \
  --workload mixed --txs 5000 --keys 500 --read-fanout 3 --write-every 1 --profile
```
- target:
  - elapsed_ms <= 300 (warn), <= 600 (hard)

### Profile C — Mixed Read-heavy
- command:
```bash
cargo run -q -p trnm-bench -- \
  --workload mixed --txs 5000 --keys 500 --read-fanout 3 --write-every 4 --profile
```
- target:
  - elapsed_ms <= 300 (warn), <= 600 (hard)

## Matrix Script
Use:
```bash
TXS=5000 ./scripts/run_bench_mixed_matrix.sh
```
Artifact pattern:
- `run/bench/bench-mixed-matrix-<timestamp>.txt`

## CI Gate Variables
In `.github/workflows/rust-l1-nightly-health.yml`:
- classic bench:
  - `BENCH_WARN_MS` (default 300)
  - `BENCH_MAX_MS` (default 600)
- mixed bench:
  - `BENCH_MIXED_WARN_MS` (default 300)
  - `BENCH_MIXED_MAX_MS` (default 600)

## Release Rule
RC requires all below in latest run:
1. `cargo test --workspace` pass
2. state root audit `ok=true mismatch=0 missing=0`
3. classic bench threshold pass
4. mixed bench threshold pass
5. `rust-l1-nightly-health` 连续 **3 次** success（同一主线分支）

## Notes
- 当前阈值基于 2026-02-19 最新实测窗口（classic/mixed 均显著低于 300ms）。
- 若 mixed profile 改参数（txs/keys/fanout/write_every），必须同步更新本文件与 workflow。
- 后续可按 7 天分位数继续收紧。
