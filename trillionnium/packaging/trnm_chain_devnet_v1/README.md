# TRNM Native PoCO Devnet Package

This package is for isolated development and reproducibility only.

It packages the self-developed native node and validator binaries, local
configuration, test identities and evidence helpers. It must not contain
production private keys and must not be described as public-testnet or
public-mainnet ready.

Before use, verify the source commit, package hashes, configuration hashes and
the `development_only` marker. Native node behavior is governed by
`../../../docs/architecture/TRNM_NATIVE_POCO_CONSENSUS.md` and current release
status by `../../../RELEASE_READINESS.md`.
