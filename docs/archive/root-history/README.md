# Archived Root History

This directory contains the repository's **former root-level history / planning documents** that are still useful for retrospective reading, but should no longer sit at the repository root and compete with the live entrypoints.

Files currently archived here:
- `STATUS.md` — historical progress log / working journal
- `ROADMAP.md` — prior-phase sprint roadmap snapshot
- `BACKLOG.md` — prior-phase backlog snapshot

Use these files for:
- historical milestone reconstruction
- understanding what the team believed at that time
- tracing earlier planning / prioritization context

Do **not** use this directory as the current truth-source for release readiness.

Current entrypoint order:
1. `RELEASE_READINESS.md`
2. `README.md`
3. `docs/development/DEVELOPMENT_MASTER_UNIFIED_2026-03-04.md`
