# P2.3 Aggressive Empty-Stage Guard (2026-02-20)

## What changed
1. Added runtime guard in executor:
- Env: `TRNM_AGGR_SKIP_EMPTY_STAGE_CHECKS`
- Default: `true`
- Disable by setting `0|false|off|no`

Behavior:
- If tx `write_set` is empty, skip WW/WR stage intersects.
- If tx `read_set` is empty, skip RW stage intersects.

2. Extended regression matrix output for observability:
- `candidate_groups_scanned`
- `stage_ww_checks/hits`
- `stage_wr_checks/hits`
- `stage_rw_checks/hits`

Updated script:
- `trillionnium/scripts/run_bench_regression_matrix.sh`

## Validation
- `cargo test -p trnm-executor -p trnm-bench` passed.
- `TXS=2000 ./scripts/run_bench_regression_matrix.sh` passed.
- Example CSV:
  - `trillionnium/run/bench/bench-regression-matrix-20260220-144217.csv`

## Notes
- Existing regression ratio checker remains compatible (uses first 6 CSV columns).
- New columns are append-only and safe for current gates.
