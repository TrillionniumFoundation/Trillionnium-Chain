# Operating scope

No consensus node is runnable after cleanup. Old launch commands, configurations, snapshots
and validator keys are not inputs to a new node. Do not deploy these portable candidates.

Worker, peer-lease and checkpoint programs are explicit local utilities with fresh private
namespaces. Stop and reconcile exact operation identities across failure; deletion is not
recovery. The worker mock adapter is a fixture, not a successful product integration.

Future native PoN startup must qualify work, forks, reorg, resource isolation, external
effects and actual public-model contribution/use. Local test success does not enable it.

A separate executable-spec peer harness binds localhost only and exits after its bounded
campaign. It performs real work/signature/state checks; it is not a production node or
a service installed on the host. See the detailed performance/acceptance contract.
