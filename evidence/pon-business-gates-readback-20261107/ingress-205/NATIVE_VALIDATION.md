## Change and boundary

The paid V3 worker can borrow a private `CanonicalPacketText` from the same
immutable raw request body. Its constructor checks the original body bound,
exact Submit prefix and suffix, even hexadecimal length, complete lowercase
ASCII grammar and UTF-8 representation. The field is private and the constructor
has only owner-module visibility; callers cannot supply a trust boolean or an
unchecked arbitrary string.

This replaces an owned hexadecimal String copy and its later repeated character
classification for **non-PQ, non-Growth V3 Submit operations**, including the
explicit classical arithmetic profile. It does not enable or enlarge a cache.
Other owned-String entries still use the original independent
`canonical_request` and checked hexadecimal decoder. The independent
serde/canonical grammar oracle is also retained.

The actual body digest and current cookie validation still precede full Packet
decoding. Packet decoding remains at the original Decode boundary and still
allocates binary bytes and copies every actual proof/transaction field through
the original `Packet::decode`. The shared Submit bodies were extracted without
changing context, owner, cancellation, Work, admission, publication, observer
or CPU callback order. A text witness grants no Work, State, authorization,
deadline or resource authority.

The raw body is still released at the original dispatch-return point. Body and
lane allowances are still released before the original owner CPU settlement.
The borrow cannot prolong either lifetime beyond those existing boundaries.
Default negative-cache observations and actual native replay remain separate.

The six changed tracked files are the two ingress owners, the new private
canonical-packet module and its tests, the existing input-decode tests, and the
source-pin manifest. The manifest retains false qualification flags and
