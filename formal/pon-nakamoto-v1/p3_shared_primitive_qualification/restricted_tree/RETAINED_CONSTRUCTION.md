# The retained shared permutation: games, a scoped classical lemma and open work

## Implementation facts and the immediate modeling correction

The pinned construction is `PaddingFreeSponge<Perm,8,4,4>` for leaves,
`TruncatedPermutation<Perm,2,4,8>` for branches and
`DuplexChallenger<Val,Perm,8,4>` for challenges, using the same public default
Poseidon2Goldilocks permutation. Let `X=F_p^4`, `N=p^4`,
`p=18446744069414584321`, and write `Pi : X x X -> X x X`.

A branch is `C(a,b)=left(Pi(a,b))`. An exactly four-field leaf is
`H4(m)=left(Pi(m,0))`. Hence `H4(m)=C(m,0)` identically. Leaf and branch calls
cannot be replaced by mutually independent ideal functions. A single shared
ideal permutation remains a coherent model; this identity is not a
contradiction in that joint model.

For any chosen `d` and distinct `r,s`, two inverse calls yield the distinct raw
inputs `Pi^-1(d,r)` and `Pi^-1(d,s)` with branch output `d`. This is a probability
one unrestricted raw-compressor collision. In the actual opening verifier,
siblings are unconstrained digest strings, but the running authenticated child
must still come from the opened leaf/path. Thus only the principal child of
each branch must be linked to the verified computation. The inverse collision
by itself supplies neither required principal leaf preimage. A theorem that
requires *all* siblings to be generated by legal subtrees is also too weak to
cover this verifier.

P3 0.8.0's duplex adds the number of absorbed elements to the first capacity
word when absorbing a nonempty buffer and zero-fills unused rate slots. Empty
buffer permutation is a pure squeeze. It therefore does not have exactly the
leaf sponge's untagged partial-block semantics. This local length tag does not
make its calls independent of other calls to the same `Pi`.

## Required games

Separate at least these five events:

| Event | Objects the adversary must supply | Status |
| --- | --- | --- |
| Raw compressor collision | Two distinct pairs in `X x X` | Two inverse-query construction exists |
| Fixed-width leaf collision | Two distinct canonical rows of the same fixed width | Narrow H4 ideal classical lemma already existed in R4 |
| Full-tree binding | Two different complete legal trees with identical fixed shape/root | Requires a tree game; raw attack alone does not win it |
| Arbitrary-path same-position binding | Two accepted conflicting rows, same root/context/index, arbitrary sibling strings | Matches the important opening-verifier restriction; scoped lemma below |
| PCS/W1 knowledge/soundness | The complete protocol's required extracted witness or forgery | Not established by any preceding event or checker |

Context must bind the profile, fixed leaf widths, dimensions, shape/cap,
ordering, index semantics and the exact serialization. Merely asking that a
branch's two input strings are “valid digests” is not a useful restriction when
every field tuple is syntactically a digest.

## Scoped proposition: classical ideal-permutation binding for ordinary paths

This proposition goes beyond the previous R4 H4-only lemma, but has narrower
scope than an actual P3 MMCS theorem. Its proof is given in full; it is not a
proof-assistant formalization and does not prove the concrete Poseidon2 case.

Sample `Pi` uniformly among permutations of `X x X`. Access is through classical
adaptive forward and inverse oracle calls. The same oracle may be queried for
any role and any other protocol; count all calls against one budget `Q`.
Advice and initial randomness are independent of `Pi`, or all queries used to
produce dependent preprocessing are included in `Q`. The model grants no free
description of the entire sampled permutation.

Fix a positive leaf width `w`, ordinary binary height `h`, and an admissible
index. Let `H_w` be the actual padding-free overwrite sponge: start with zero
state, overwrite at most four rate fields from each block, leave any other rate
fields as they stood, then permute; output the first four fields. There are
`b=ceil(w/4)` calls. The index may also be adversarially chosen, provided both
openings use the same validated index and fixed shape.

The adversary returns a root and two rows `m != m'` in `F_p^w`, with `h` arbitrary
siblings per path. Verify them using `H_w` and `C`, with identical orientation
at every level. Verification appends at most `2(b+h)` oracle calls. Put
`T=Q+2(b+h)`. For `T <= N^2`,

\[
\Pr[\text{both conflicting openings accept}]
 \le \min\left(1,\frac{2NT^2}{N^2-T+1}\right).
\]

For larger `T`, use 1. The constant is deliberately conservative. This is a
classical ideal-permutation statement, not a quantum-query bound or a concrete
Poseidon2 collision theorem. It is compatible with the probability-one raw
inverse collision because a raw collision need not be connected to a legal
leaf-derived computation.

### Proof

Lazily expose the consistent permutation table. Classify each fresh table pair
by the direction of its **first** exposure: F for forward, I for inverse.
Repeated queries retain that origin. Write a pair as `(a,b) -> (u,v)`.

Define the following bad events at a fresh exposure:

- For an F pair: its left output equals the left output of an earlier F pair,
  or its right output equals the right output of an earlier F pair; **or** one
  of its output halves equals either input half of any earlier I pair.
- For an I pair: one of its input halves equals zero, or one of its input halves
  equals either output half of any earlier F pair.

These events concern equality in `X`, not equality of individual field words.
They deliberately do not prohibit collisions between two I-origin output
prefixes. Such collisions include the known unrestricted attack.

At fresh exposure `j`, there are `M-j+1` unused full inputs and outputs, where
`M=N^2`. Given the previous classical transcript, a fresh forward output is
uniform over unused outputs, and a fresh inverse input is uniform over unused
inputs. A specified half-value has at most `N` compatible full pairs.

If there are `f` earlier F pairs and `r` earlier I pairs (`f+r=j-1`), an F
exposure has bad probability at most `(2f+4r)N/(M-j+1)`: the two same-coordinate
F/F collisions contribute at most `2fN`, and its two output halves hitting the
`2r` earlier I input halves contribute at most `4rN`. An I exposure has bad
probability at most `(4f+2)N/(M-j+1)`: two input halves must avoid at most `2f`
earlier F output halves and zero. Both are bounded by
`(4j-2)N/(M-j+1)`. Overlap or previously used pairs can only lower the numerator.

Now assume no bad event occurred during the adversary and both verifications.

First, every pair used in a legal leaf computation or its authenticated running
path has F origin. The first leaf input has capacity zero, so it could not have
I origin. For any following leaf call its capacity is the preceding call's
right output. For any branch call its principal child is the preceding derived
call's left output. Inductively suppose this preceding pair has F origin.
If the new pair had I origin, its input half would equal that F output half.
If I was exposed later, the I event would be bad; if I was exposed earlier,
the F event would be bad. The two table pairs cannot have the same exposure
and different origins. Hence the derived pair also has F origin. This argument
places no condition on sibling reachability.

Second, among the F-origin pairs, the left-output projection is injective and
the right-output projection is injective: the later of two pairs with an equal
corresponding output half would have been a bad F exposure.

Third, `H_w` is injective on the evaluated rows in a no-bad transcript. Equal
leaf outputs imply identical final F-origin table pairs by left-output
injectivity, and hence identical input states. The newly overwritten fields of
the final block are equal. If earlier blocks exist, equal capacity halves are
equal right outputs of the preceding F pairs, so right-output injectivity makes
those preceding pairs identical. Repeat backwards. Each fixed block position
has identical overwritten message fields. The first block's zero state ends
the induction. Fixed positive width is essential; differing widths or empty
input are not silently admitted.

Finally, equal roots imply identical last F-origin table pairs. Their ordered
input pairs are equal. Because the two verifications have the same orientation,
the running authenticated child digests are equal. Repeat down the fixed path
to obtain equal leaf digests and, by the preceding argument, equal rows. This
contradicts `m != m'`. Therefore winning requires a bad event.

Sum the conditional bounds over at most `T` fresh exposures, using probability
zero for unused opportunities in a stopped run:

\[
\Pr[\mathrm{bad}]
\le \sum_{j=1}^{T}\frac{(4j-2)N}{N^2-j+1}
\le \frac{N}{N^2-T+1}\sum_{j=1}^{T}(4j-2)
=\frac{2NT^2}{N^2-T+1}.
\]

This is a conditional union bound. It assumes no independence between roles,
queries or bad events. The bound is capped by 1. QED.

### Exact scope still missing

The proposition does not establish variable-shape or variable-width binding,
P3 mixed-height row injection or pruned multiproof reconstruction, vector or
knowledge extraction, a quantum lazy-sampling argument, transcript
pseudorandomness, Fiat-Shamir soundness, or a theorem for fixed public Poseidon2.
Arbitrary other-role primitive calls are permitted in `Q`, so this binding
subgame is already **joint-oracle aware**. That does not supply the remaining
properties of the joint leaf/branch/transcript protocol model.

The exact old P3 widths may make `b` large. Every verifier hashing operation and
all underlying permutation invocations must be counted. A new domain label
never resamples the shared permutation. Lifetime/offline/adversarial costs
cannot be omitted by counting only submitted proofs.

## Sharp structural controls that do not claim a W1 attack

### Different leaf widths

For the untagged first block,
`H2(a,b)=H4(a,b,0,0)` for every permutation. Identical arbitrary paths preserve
the equality. This is a perfect cross-width encoding alias; it is outside the
same-fixed-width game and cannot be dismissed by an ideal-permutation bound.

### Different authenticated path shapes

Choose any four-field message `m` and let `a=H4(m)` and `R=H4(a)`.
A height-zero opening with row `a` has root `R`. A height-one opening with row
`m`, index zero and sibling `0` has root `C(a,0)=R`. Both are valid in their own
ordinary path contexts. This is a perfect cross-shape alias when the verifier
allows such a context change. It does not show an attack on a verifier that
binds its dimensions/profile and it does not supply a complete legal sibling
subtree hashing to zero.

### Padding-free final-block aliases

A shorter final block leaves unfilled rate positions from the preceding
permutation output; a longer final block can explicitly supply those same
values. The two different message lengths then produce the identical final
state. Fixed widths avoid this within one leaf role, while unframed variable
length usage does not. The duplex's length tag must be examined separately.

### Preprocessing advice

For fixed `w>4`, `|F_p^w| > |F_p^4|`, so a collision for `H_w` exists for **every**
permutation by the pigeonhole principle. Unrestricted free advice correlated
with the permutation may encode such a pair and return it with no charged
online search. This is not an efficient discovery algorithm; it is a decisive
counterexample to a theorem that charges only online queries while permitting
arbitrary dependent advice. Charge preprocessing or state an explicit bounded
auxiliary-information assumption. A published concrete permutation additionally
needs an instantiation argument, not just the ideal table analysis.
