## Cost units and physical ownership

Keep these measurements separate:

1. The sum of actual producer CPU (preparation plus all search attempts), actual
   full native verifier CPU and typed-copy CPU. This is a local native work
   subtotal, not total system cost and not a theoretical lower bound.
2. Native child process CPU/wall, including diagnostics, scalar reference
   verification, JSON creation, serialization and startup/exit.
3. The inner research campaign CPU/wall, including input validation, source
   replay, material packing, ordinary baseline repetitions, consumer and other
   diagnostics. Parent CPU plus all reaped children is charged once. The native
   child subtotal is a subset, not another additive term.
4. The campaign driver's outer consumer-process-tree cost, which additionally
   includes interpreter imports and final report/exit. It overlaps the inner
   campaign and must never be added to it.

The first four actual runs satisfy both outer CPU and outer wall containment of
the inner campaign. Their per-tile child clocks and native subtotals also pass
the final strict reader. A baseline's CPU median may be compared with the native
CPU subtotal; a wall median may be compared with sequential native wall. CPU and
wall are not interchangeable or additive. A sequential sum of local verifier
wall clocks is not latency at N independent nodes.

The native work subtotal excludes Python input/model validation, source replay,
material packing, final Python aggregation/routing, reference diagnostics,
logging/transport and process overhead. These appear elsewhere in local records;
they have not disappeared. The input phase combines model/task loading and
optional source replay and must not be described as isolated production device
loading. Whole-experiment time is not one inference latency.

Full-system cost and net benefit remain null because competing miners,
abandoned work, actual network validator population, WAN propagation, stale
blocks, device/model distribution/loading, energy and real ledger/effect costs
are not completely measured. Local pipe bytes overlap semantic input, proof and
product byte counts. Do not sum those two views of the same traffic.
